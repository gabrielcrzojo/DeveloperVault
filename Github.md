**GitHub** é uma plataforma de desenvolvimento colaborativo que utiliza **Git** para hospedar e gerenciar repositórios de código.  
Permite armazenar projetos remotamente, acompanhar seu histórico e trabalhar em equipe.  
Possui recursos como **Branches, Pull Requests, Issues, Forks e Code Review** para organizar o desenvolvimento.  
Também oferece **GitHub Actions**, que permite automatizar tarefas como testes, builds e processos de CI/CD.  
Repositórios podem ser públicos ou privados e possuem sistemas de permissões para controlar o acesso.  
O fluxo comum envolve desenvolver com Git localmente, enviar os commits para o GitHub e utilizar Pull Requests para revisar e integrar alterações.
