**Bun** é um runtime para **JavaScript e TypeScript** que também integra gerenciador de pacotes, bundler, test runner e executor de scripts. Foi desenvolvido para oferecer alto desempenho e simplificar o desenvolvimento de aplicações web. Possui compatibilidade com grande parte do ecossistema Node.js e npm. Pode ser utilizado tanto para executar aplicações backend quanto para gerenciar o desenvolvimento e build de projetos frontend. Atua na camada de **Runtime e Tooling**.
