**Redis (Remote Dictionary Server)** é um sistema de armazenamento de dados NoSQL baseado principalmente em memória RAM, que utiliza o modelo chave-valor para oferecer acesso rápido às informações. Suporta diferentes estruturas de dados, como strings, listas, hashes, conjuntos e streams, além de recursos como expiração automática de chaves (TTL) e persistência opcional em disco. É amplamente utilizado para cache, gerenciamento de sessões, rate limiting, contadores e mensageria. Seu principal objetivo é proporcionar operações de baixa latência, reduzindo consultas repetidas e melhorando o desempenho de aplicações.
