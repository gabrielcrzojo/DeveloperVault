**Swagger** é um conjunto de ferramentas utilizado para documentar, visualizar e testar APIs.  
Ele trabalha principalmente com a especificação **OpenAPI**, que descreve endpoints, parâmetros, respostas, autenticação e modelos de dados.  
O **Swagger UI** transforma essa especificação em uma documentação interativa acessível pelo navegador.  
Através dela, é possível visualizar os endpoints e executar requisições utilizando o recurso **Try it out**.  
Frameworks como **FastAPI** podem gerar automaticamente a especificação OpenAPI e disponibilizar uma interface Swagger UI.  
**OpenAPI** é o padrão de especificação, enquanto **Swagger** é o ecossistema de ferramentas que utiliza essa especificação.
