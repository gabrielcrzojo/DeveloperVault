**NumPy** é uma biblioteca Python voltada para computação numérica e manipulação eficiente de dados.  
Sua principal estrutura é o `ndarray`, que permite trabalhar com vetores e matrizes multidimensionais.  
Facilita operações matemáticas, estatísticas, álgebra linear e geração de números aleatórios.  
É mais eficiente que listas Python para operações numéricas em grandes volumes de dados.  
Serve como base para várias bibliotecas científicas e de análise de dados.  
O Pandas utiliza conceitos e estruturas do NumPy internamente.
