**Docusaurus** é um framework de código aberto desenvolvido pela Meta, baseado em React e Node.js, utilizado para criar e publicar sites de documentação técnica. Funciona como um gerador de sites estáticos (SSG), convertendo arquivos Markdown/MDX e componentes React em páginas HTML, CSS e JavaScript. Oferece suporte a versionamento de documentação, internacionalização (i18n), temas personalizáveis, plugins, busca e integração com CI/CD. O uso de MDX permite incorporar componentes React interativos diretamente na documentação. É amplamente utilizado para documentar projetos de software, bibliotecas, frameworks, APIs e portais de desenvolvedores, podendo ser hospedado em plataformas como GitHub Pages, Netlify e Vercel.

https://docusaurus.io/
