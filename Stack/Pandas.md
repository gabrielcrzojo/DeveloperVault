Pandas é uma biblioteca Python voltada para **manipulação e análise de dados**. Utiliza estruturas como `DataFrame` e `Series` para trabalhar com dados tabulares de forma eficiente. Permite carregar, limpar, filtrar, transformar, agrupar e analisar dados provenientes de diferentes fontes e formatos. É amplamente utilizada em **Data Science, Machine Learning e processamento de dados**, servindo como uma das principais ferramentas para preparação e exploração de datasets.
