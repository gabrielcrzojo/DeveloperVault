**OpenAPI** é uma especificação padrão utilizada para descrever APIs HTTP de forma estruturada e independente da linguagem de programação.  
Define endpoints, métodos HTTP, parâmetros, requisições, respostas, códigos de status, modelos de dados e autenticação.  
A especificação pode ser escrita em **YAML ou JSON** e funciona como um contrato entre consumidores e desenvolvedores da API.  
A partir dela, ferramentas podem gerar documentação interativa, clientes e recursos de teste automaticamente.  
O **Swagger UI** é uma das principais ferramentas utilizadas para visualizar e testar uma especificação OpenAPI.  
Frameworks como **FastAPI** podem gerar automaticamente a especificação OpenAPI com base na definição da API.
