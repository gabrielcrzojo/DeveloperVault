SQLAlchemy é um toolkit e **ORM para Python** utilizado para conectar aplicações a bancos de dados relacionais. Permite representar tabelas como classes Python e realizar consultas, inserções, atualizações e relacionamentos através de uma interface programática. Também oferece recursos de conexão e gerenciamento de transações. Possui o **Core**, para trabalhar diretamente com estruturas SQL, e o **ORM**, para mapeamento objeto-relacional. Atua na camada de **persistência de dados do Backend**.
