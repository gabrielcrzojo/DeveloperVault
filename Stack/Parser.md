**Parser (Analisador Sintático)** é um componente responsável por analisar a estrutura de uma sequência de dados ou código, verificando se ela segue determinadas regras gramaticais. Organiza os elementos em uma estrutura compreensível, podendo gerar uma AST (Abstract Syntax Tree). É utilizado em compiladores, interpretadores e no processamento de formatos como JSON, XML e HTML.

- **Lexer:** identifica os elementos individuais.
    
- **Parser:** analisa e organiza sua estrutura.
    
- **AST:** representa hierarquicamente a estrutura analisada.
