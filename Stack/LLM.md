**LLM (Large Language Model)** é um modelo de inteligência artificial treinado com grandes volumes de dados para compreender e gerar linguagem natural.  
Utiliza principalmente a arquitetura **Transformer** e mecanismos de **Attention** para identificar relações entre diferentes partes do texto.  
A partir de um _prompt_, o modelo processa o contexto e gera uma resposta prevendo os próximos tokens.  
Pode ser utilizado para conversação, geração e análise de textos, tradução, resumo, classificação e geração de código.  
Exemplos de famílias de LLMs incluem **GPT, Claude, Gemini, Llama e Mistral**.  
LLMs podem ser integrados a aplicações por meio de APIs, permitindo adicionar recursos de IA a sistemas existentes.
