**Git** é um sistema de controle de versão distribuído usado para acompanhar e gerenciar alterações em projetos.  
Ele mantém um histórico das modificações por meio de **commits**, permitindo consultar, comparar e recuperar versões anteriores.  
Utiliza **branches** para desenvolver funcionalidades, correções ou experimentos de forma isolada.  
Por ser distribuído, cada repositório possui seu próprio histórico e pode ser utilizado localmente sem depender de um servidor.  
É amplamente utilizado em equipes para organizar o desenvolvimento e facilitar a colaboração no código-fonte.

## Principais comandos do Git

### Iniciar um repositório

```
 git init
```

### Clonar um repositório

```
 git clone <url
```

### Verificar alterações

```
 git status
```

### Adicionar alterações

```
 git add .
```

### Registrar alterações

```
 git commit -m "mensagem"
```

### Enviar alterações

```
 git push
```

### Baixar e integrar alterações

```
 git pull
```

### Criar ou visualizar branches

```
 git branch
```

### Trocar de branch

```
 git switch <branch>
```

### Visualizar o histórico

```
 git log
```

### Buscar alterações remotas

```
 git fetch
```

### Mesclar branches

```
 git merge <branch
```

### Desfazer alterações

```
 git reset <arquivo
```

### Guardar alterações temporariamente

```
 git stash
```

### Visualizar diferenças

```
 git diff
```
