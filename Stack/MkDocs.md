**MkDocs** é um gerador de sites estáticos (SSG) de código aberto, desenvolvido em Python, especializado na criação de documentação técnica a partir de arquivos Markdown. Utiliza um arquivo de configuração YAML (`mkdocs.yml`) para definir temas, navegação, plugins e estrutura do site. Converte arquivos Markdown em páginas HTML, CSS e JavaScript, permitindo publicar documentações sem a necessidade de um backend. Oferece servidor de desenvolvimento com Live Reload, suporte a plugins, personalização visual e integração com pipelines CI/CD. É amplamente utilizado para documentar projetos de software, bibliotecas, frameworks e APIs, podendo ser combinado com o tema Material for MkDocs e hospedado em plataformas como GitHub Pages, Netlify e Vercel.

https://www.mkdocs.org/
