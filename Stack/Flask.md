**Flask** é um microframework web para **Python** utilizado para desenvolver aplicações web e APIs HTTP/REST. Fornece recursos essenciais como roteamento, processamento de requisições e geração de respostas, mantendo a arquitetura simples e flexível. Por não impor uma estrutura completa, funcionalidades adicionais podem ser incorporadas conforme a necessidade do projeto. É utilizado principalmente na camada de **Backend**, atuando como servidor da aplicação e API.
