PyAutoGUI é uma biblioteca Python para **automação de interfaces gráficas**. Permite controlar programaticamente o mouse e o teclado, escrever textos, pressionar teclas, tirar screenshots e interagir com elementos visuais da tela. É útil para automatizar tarefas repetitivas em aplicações desktop ou sistemas que não possuem uma API disponível. Atua na camada de **Automação/RPA**, simulando a interação de um usuário com a interface.
