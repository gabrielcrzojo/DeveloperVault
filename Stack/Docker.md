**Docker** é uma plataforma de containerização usada para empacotar e executar aplicações junto com suas dependências em ambientes isolados.  
Uma aplicação é definida normalmente através de um **Dockerfile**, que é utilizado para construir uma **imagem Docker**.  
A partir da imagem, podem ser criados **containers**, que executam a aplicação de forma padronizada.  
Isso facilita o desenvolvimento, testes e implantação, reduzindo diferenças entre ambientes.  
O **Docker Compose** permite configurar e executar vários containers relacionados como uma única aplicação.  
Docker é muito utilizado para ambientes de desenvolvimento, bancos de dados, APIs, microsserviços e processos de **CI/CD**.
