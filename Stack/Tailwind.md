Tailwind CSS é um framework CSS baseado em _utility classes_, permitindo construir interfaces diretamente no HTML/JSX através da combinação de classes pequenas e reutilizáveis. Facilita a criação de layouts, tipografia, cores, espaçamentos, responsividade, estados e temas. Seu objetivo é acelerar o desenvolvimento e manter a estilização consistente, gerando apenas o CSS necessário para as classes utilizadas. É utilizado na camada de **Frontend**, junto de tecnologias como React e JavaScript.

https://tailwindcss.com/
