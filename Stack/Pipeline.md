**Pipeline** é uma sequência de **etapas automatizadas** que processam uma tarefa de forma ordenada. Em desenvolvimento de software, é comum em **CI/CD** para automatizar processos como instalação de dependências, testes, análise, build e deploy. Cada etapa pode depender do sucesso da anterior, garantindo que apenas código validado avance no processo. É um conceito de **DevOps e automação**, podendo ser implementado por ferramentas como GitHub Actions, GitLab CI/CD e Jenkins.
