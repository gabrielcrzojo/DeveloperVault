**Pyperclip** é uma biblioteca Python usada para acessar e manipular a **área de transferência (clipboard)** do sistema.  
Permite copiar textos para o clipboard usando `pyperclip.copy()` e obter textos usando `pyperclip.paste()`.  
É útil em scripts de automação que precisam transferir informações entre o Python e outros programas.  
Pode ser combinado com **PyAutoGUI** para criar automações que copiam, colam e interagem com interfaces gráficas.  
Seu objetivo principal é facilitar o controle de texto no clipboard sem precisar lidar diretamente com as APIs específicas de cada sistema operacional.
