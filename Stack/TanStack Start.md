TanStack Start é um framework full-stack para React baseado no TanStack Router. Permite construir frontend e funcionalidades de servidor em uma única aplicação, oferecendo SSR, streaming, rotas de API, server functions e middleware. Utiliza Vite ou Rsbuild para desenvolvimento e build. Possui suporte a TypeScript e busca fornecer type safety de ponta a ponta. É utilizado na camada de **arquitetura Full-stack** para estruturar aplicações React modernas.
https://tanstack.com/start/latest
