**REST API** é uma API baseada nos princípios do **REST**, utilizada para permitir a comunicação entre sistemas através do HTTP. Organiza os dados como **recursos** e utiliza métodos como GET, POST, PUT/PATCH e DELETE para manipulá-los. As informações são frequentemente transmitidas em **JSON** e as requisições seguem o princípio _stateless_. REST é um **estilo arquitetural**, não uma tecnologia específica, e pode ser implementado com frameworks como FastAPI e Flask. Atua principalmente na camada de **Backend e comunicação entre aplicações**.

- **GET** → consultar recursos
- **POST** → criar recursos
- **PUT/PATCH** → atualizar recursos
- **DELETE** → remover recursos
