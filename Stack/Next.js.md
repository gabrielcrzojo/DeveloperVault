**Next.js** é um framework baseado em **React** para criação de aplicações web modernas. Ele adiciona recursos como roteamento, SSR, geração estática, Server Components, otimizações e funcionalidades executadas no servidor. Permite combinar **SSR, SSG e CSR** conforme a necessidade da aplicação. Também pode ser utilizado para desenvolver aplicações full-stack, reunindo frontend e funcionalidades server-side em um mesmo projeto. Atua na camada de **Framework Web/Frontend**, podendo também assumir responsabilidades de backend.
