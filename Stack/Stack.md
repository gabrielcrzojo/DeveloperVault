Esta nota é o ponto de entrada da base de conhecimento sobre desenvolvimento de software no Obsidian. Seu intuito é organizar o acesso às principais áreas de estudo e facilitar a navegação entre as anotações, reunindo aprendizados, referências e insights construídos durante estudos e projetos. Funciona como um guia para consultar e revisar o conhecimento acumulado, mantendo uma visão geral dos assuntos que compõem a stack de desenvolvimento.
